Contoh: gemini-2.0-flash, gpt-4o-mini, deepseek-chat
Standar Instagram: 5 slide (Hook, Konteks, Data, Implikasi, CTA).
Kata-kata ini dilarang keras muncul di headline, slide, maupun caption Instagram.
File tersimpan di config/skills/copywriter.skills.md dan otomatis diinjeksi ke system prompt LLM Copywriter.
