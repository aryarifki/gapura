✍️ Konfigurasi Agen Copywriter

Karakteristik Brand Data-Editorial

Mengatur model teks AI, jumlah slide carousel, nada suara, kata-kata terlarang, dan klausul disclaimer.

Contoh: gemini-2.0-flash, gpt-4o-mini, deepseek-chat
Standar Instagram: 5 slide (Hook, Konteks, Data, Implikasi, CTA).
Kata-kata ini dilarang keras muncul di headline, slide, maupun caption Instagram.
File tersimpan di config/skills/copywriter.skills.md dan otomatis diinjeksi ke system prompt LLM Copywriter.

🎨 Konfigurasi Agen Designer (Full AI Visual Architect)

AI Dynamic Layouts & Brand Tokens

Agen Designer sepenuhnya otonom ditenagai AI: menentukan sendiri jumlah slide, merancang struktur visual per slide secara bebas tanpa batasan template kaku, serta mengekstrak data visual dari berita secara cerdas.

Contoh: gemini-2.0-flash, gpt-4o, deepseek-chat
File tersimpan di config/skills/designer.skills.md dan otomatis diinjeksi ke system prompt AI Designer.
